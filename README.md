# Janko Visuals

Sajt za Janko Visuals, napravljen u Next.js. Svaki push na `main` granu Vercel automatski objavljuje.

## Gde se šta menja

- `content/site.js`: sav tekst sajta (naslovi, radovi, klijenti, koraci procesa, mejl, Calendly link).
- `app/page.js`: raspored sekcija.
- `app/globals.css`: izgled (boje, fontovi, razmaci).
- `components/Interactions.js`: animacije i ponašanje (meni, horizontalni niz radova, vremenska linija).
- `public/`: slike i video fajlovi radova.

## Lokalno pokretanje

```bash
npm install
npm run dev
```

Sajt je na http://localhost:3000.
